# Code of conduct

Be respectful of participants with different backgrounds and experience levels. Discuss code and mathematics using reproducible evidence, provide useful context, receive constructive feedback in good faith and respect others' time.

Harassment, discrimination, insults, threats, persistent personal attacks, disclosure of private information and deliberate disruption are not acceptable. Challenge claims with evidence while treating the person respectfully.

Maintainers may edit or remove harmful content, restrict participation, issue warnings or ban participants proportionately. Context and reporter privacy should be considered. The same standards apply to maintainers.

Use a contact channel actually listed on the [maintainer profile](https://github.com/plateboheng-cell) if available. Do not publish another person's private information while reporting misconduct. This project does not promise a dedicated private reporting service or a fixed response time.
