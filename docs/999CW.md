### 分布

提供二项 PD/CD、正态 PD/CD、左尾逆正态、泊松 PD/CD 七项。离散分布可逐行录入最多 45 个 x，确认参数后在同一列表显示 P。方向键选格，DEL 删除行，工具菜单可插入行或全部删除。编辑 x 会清除 P，变量键可存储选中格的值。无效 x 在该行显示错误，公共参数无效时拒绝执行。

标量结果写入 Ans 并保留近似来源。OK 或 EXE 可返回参数页。参数按名称在当前会话共享，启动其他应用会清空 x 列表。ON、关机和「设置 & 数据」复位会清空参数和列表。重启 Windows 应用或切换型号也会开启新的分布会话。

测试覆盖手册中 N=5、p=0.5、x={2,3,4,5} 的二项累积概率，以及 x=36、μ=35、σ=2 的正态密度。二项和泊松用对数概率与单侧递推，正态窄区间直接积分。二项 N、离散 x 和泊松 λ 的上限为 10 亿，N 和 x 须为非负整数，λ 可为 0。分布引擎使用双精度，显示遵循格式设置。

分布类型菜单中按 TOOLS 可打开「扩展分布」，直接计算二项、泊松、正态右尾概率或右尾反正态。反正态面积为 0 或 1 时，本实现显示数学极限 ±∞，并保留最近的有限 Ans。第一代说明书给出含端点的参数范围，真机端点显示仍待实测。[第一代分布说明](https://support.casio.com/global/cn/calc/manual/fx-991CNCW_999CNCW_cn/using_calculator_apps/distribution_calculations.html)

### 数据表格

- A1:E45 共 225 格。浏览时 OK 或 EXE 进入编辑，编辑时同一个键确认并下移。直接键入会替换当前格。
- 不带 `=` 的表达式计算一次成为常数，保留十位有效数字。以 `=` 开头的公式依赖其他单元格，自动重算可关闭。
- 支持相对引用、`$A1`、`A$1`、`$A$1` 和 `Sum/Mean/Min/Max(A1:B3)` 矩形范围计算。`2E10` 表示 2 乘以 E10，十进制指数可以写作 `2e10`。符合条件的实数公式引用保留最多 23 位有效数字。空格作为 0 参与算术，聚合忽略空格。空范围 Sum 为 0，其他聚合报错。
- 工具提供填充、复制和剪切模式、全部删除、剩余容量、自动计算、显示单元格和重算。用 OK 或 EXE 粘贴，复制模式可连续粘贴，剪切模式在一次成功粘贴后退出。越界复制产生错误格。循环单格输入拒绝并保留旧数据。
- 目录的「数据表格」子菜单提供抓取引用、`$`、`:` 和聚合命令。变量键可存储当前格的结果。关闭自动计算后，其他格的公式保留上次结果，直至手动重算。变量、角度单位和 f/g 的变更可通过手动重算反映到表中。
- 原机容量模式按文本词法模拟 49 输入字节和 1700 总字节。函数命令计一个字节，常数 14 字节，公式额外 15 字节。固件连续依赖链的额外内存阈值待实测。[第一代数据表格说明](https://support.casio.com/global/cn/calc/manual/fx-991CNCW_999CNCW_cn/using_calculator_apps/using_spreadsheet.html) · [内存错误说明](https://support.casio.com/global/cn/calc/manual/fx-991CNCW_999CNCW_cn/technical_information/errors.html)
- 表格在会话内跨应用保留，ON、关机、重启 Windows 应用、切换型号或「设置 & 数据」复位都会清空表格内容。

在 TOOLS → 桌面工作表中可启用扩展容量。扩展模式允许填满 225 格，每格最多 128 个输入字节，总容量 32,175 字节。可保存本地 JSON 文件，之后恢复公式、常数、当前选中格和容量模式。恢复会按当前计算设置重算，替换有内容的工作表前会要求确认。

手册的 35、42、49 和 Sum=126，以及公式填充 `2A1-3` 和数值填充 `B1×3` 均有独立计算与 Electron 操作测试。

## 计算、显示与复位

计算和复数应用提供运算验证。它按当前变量数值求每边的结果，显示 True 或 False 并写入 1 或 0 到 Ans。计算应用提供手动分数化简、多语句和目录中的变量赋值命令。显示设置包括四种输入输出组合、Fix/Sci/Norm 1/Norm 2、分数和复数形式、工程符号、小数点及分隔符。

### 复数输入与结果

在复数应用中用 SHIFT → 8 或 CATALOG → 复数 → ∠ 输入极坐标。数学和线性模式均按说明书处理极坐标与省略乘号、排列组合、乘除的优先级。FORMAT 可在代数式与极坐标间切换。数学输入/数学输出合并显示两个分量，其余三个输入/输出设置分行显示。方程应用可以单独切换当前复数根的坐标形式。[第一代复数计算](https://support.casio.com/global/cn/calc/manual/fx-991CNCW_999CNCW_cn/using_calculator_apps/complex_number_calculations.html) · [复数根的格式转换](https://support.casio.com/global/cn/calc/manual/fx-991CNCW_999CNCW_cn/changing_calculation_result_format/rectangular_and_polar_coordinate_conversion.html)

复数四则、整数次幂、极坐标输入、平方根、对数、模、辐角、共轭和分量提取可使用每个分量 23 位的十进制运算。复数整数次幂支持绝对值小于 `10^10` 的指数。Ans 和变量档案保存这两个分量的低位，验证等式时会用上保存的精度。复数三角函数和部分非整数幂由数值引擎计算。[第一代运算验证](https://support.casio.com/global/cn/calc/manual/fx-991CNCW_999CNCW_cn/using_verify/verify_overview.html)

计算器 ON、SHIFT → AC 关机和自动关机按计算器电源流程清除变量、Ans、f/g 及会话数据。关闭 Windows 窗口会保存档案，便于下次打开。HOME 清除计算历史，「变量存储器」复位清除变量和 Ans，「设置 & 数据」复位保留变量、Ans、语言和对比度，「全部初始化」保留语言和对比度。

### 输入、撤消与重放

在计算或复数的算式页，TOOLS → 撤消会恢复上一笔输入的公式和光标，再执行一次会重做。电脑键盘的 Ctrl+Z 与 Ctrl+Y 可以逐步撤消和重做。撤消同时处理数学模板和线性输入，返回目录后保留原来的选区。

数学输入时，SHIFT＋左／右可越过当前模板。SHIFT＋DEL 选择光标右侧的参数，接着按根号等函数键即可包裹该参数。手册例子可把 `1+7/6` 中的竖式分数用作根号的自变量。线性输入中的 SHIFT＋DEL 切换覆盖输入。[第一代数学输入说明](https://support.casio.com/global/cn/calc/manual/fx-991CNCW_999CNCW_cn/inputting_expressions_and_values/inputting_an_expression_using_natural_textbook_format.html)

计算、复数和基数的上／下键浏览历史。结果较宽时，屏幕会标出仍可查看的方向，左右键滚动结果，按返回可进入原算式。此时按 AC 清屏，下一次按左／右也可调回该算式。普通结果按左键从式末开始重放，手册的 `4×3+2 → 4×3−7` 键序可直接操作。编辑和滚动期间，Ans 仍为上次执行的值。[第一代计算历史与重放](https://support.casio.com/global/cn/calc/manual/fx-991CNCW_999CNCW_cn/basic_calculations/calculation_history.html)

### 目录与工程记数法

通用目录可在计算、复数、统计、矩阵和向量的算式页使用，也可向分布参数、工作表和可编辑的系数格插入相应命令。目录按应用筛选命令。插入会回到原输入位置，基数应用保留专用进制和逻辑目录。[高级计算与适用范围](https://support.casio.com/global/cn/calc/manual/fx-991CNCW_999CNCW_cn/advanced_calculations/index.html)

CATALOG → 工程符号提供 11 个输入倍率。线性输入使用独立字形区分工程符号、变量和科学计数法。开启工程符号显示后，`999k + 25k` 得到 `1.024M`。用 FORMAT → 工程记数法进入移位，左右键每次移动三位，EXE 或返回退出并保留当前显示。移位只改变显示，Ans 仍是原数值。[工程符号](https://support.casio.com/global/cn/calc/manual/fx-991CNCW_999CNCW_cn/advanced_calculations/engineering_symbols.html) · [工程记数法](https://support.casio.com/global/cn/calc/manual/fx-991CNCW_999CNCW_cn/changing_calculation_result_format/engineering_notation.html)

度、弧度、百分度后缀把输入转换为当前角度单位。百分号把它所跟随的量除以 100。线性排列、组合、内积和求余数使用原来的运算位置。Rnd 在内部按 Fix 或 Sci 设置舍入，Norm 使用 11 位有效数字，计算和工作表公式使用同一舍入规则。[角度后缀](https://support.casio.com/global/cn/calc/manual/fx-991CNCW_999CNCW_cn/advanced_calculations/angle_unit.html) · [计算优先顺序](https://support.casio.com/global/cn/calc/manual/fx-991CNCW_999CNCW_cn/technical_information/calculation_priority_sequence.html) · [Rnd](https://support.casio.com/global/cn/calc/manual/fx-991CNCW_999CNCW_cn/advanced_calculations/numeric_calculations.html)

### 23 位实数计算

四则运算、乘方、根、对数、三角和双曲函数、阶乘及排列组合等符合条件的实数算式采用 23 位有效数字。符合条件的 f/g 调用也在同一精度下求值。Ans 和标量变量把十进制低位随档案保存，显示仍按 Norm、Fix 或 Sci 取位。用例覆盖 `10^20+1` 保存后再减去 `10^20`、三种角度单位的三角函数边界以及阶乘上限。非零幅值小于 `10^-99` 的实数结果按零处理。[计算范围、位数和精确度](https://support.casio.com/global/cn/calc/manual/fx-991CNCW_999CNCW_cn/technical_information/calculation_ranges.html)

计算页可连续输入 `2°20°30°+0°9°30°` 并切换六十进制和小数显示。单位换算按手册分为九类共 40 条命令，可跟在原算式后执行。普通对数 `log(a,b)` 以第一个参数为底数，数学模板 `logₐ(b)` 仍按底数槽输入。线性输入会按手册将 `6÷2(1+2)` 分组为 `6÷(2(1+2))`。[六十进制](https://support.casio.com/global/cn/calc/manual/fx-991CNCW_999CNCW_cn/changing_calculation_result_format/sexagesimal_conversion.html) · [单位换算](https://support.casio.com/global/cn/calc/manual/fx-991CNCW_999CNCW_cn/advanced_calculations/unit_conversions.html) · [基本输入规则](https://support.casio.com/global/cn/calc/manual/fx-991CNCW_999CNCW_cn/inputting_expressions_and_values/basic_input_rules.html)

## 验收范围

状态为 **Experimental**。按说明书运行可重复的按键和数值示例。复数、矩阵、分布和数值积分采用各应用的软件算法。完整 LCD 字库、各应用目录和部分错误光标位置、分布端点及表格依赖链的固件内存阈值仍待逐项对照。HOME 下的计算器 ID 页面显示型号。

## English scope

The first-generation fx-999CN CW remains **Experimental**. The main workflows in all twelve applications follow the first-generation manual. Supported real expressions and stored scalar values use 23 significant decimal digits. The complete catalog, screen glyphs and several firmware boundary cases remain partial. Complex and numerical applications use their own algorithms.

Run `npm test`, `npm run build`, and on Windows `npm run test:ui:999` or the full `npm run test:ui`. Actual results are recorded in [VERIFICATION.md](VERIFICATION.md).
