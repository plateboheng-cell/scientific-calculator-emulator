官方图片与手册仅保存在本地忽略目录用于研究。应用使用原创 CSS/SVG，机身和保护盖不附加软件项目字样，没有厂商 Logo、机身图片或固件。外壳参考白色款，共用该代 CW 的 48 键位置和 SHIFT 层。

## 相对 991CN CW 的实际差异

HOME 按说明书顺序显示十二项：计算、统计、分布、数据表格、函数表格、方程、不等式、复数、基数、矩阵、向量、比例式。方向键、翻页键与 OK 可选择全部应用。电脑键盘 `1–9, 0, A, B` 也可直达，不将这些快捷键称作新增实体键。991CN CW 保持原来的十项，不会得到 999 专用应用。

### 分布

提供二项 PD/CD、正态 PD/CD、左尾逆正态、泊松 PD/CD 七项，支持离散分布的变量或 1–45 项列表。输入无效的单个 x 在该行显示错误；公共参数无效时拒绝计算。标量结果写入本型号 Ans 并保留近似来源，显示 `≈` 小数，不转换为精确分数或根式。参数按名称在当前会话共享；启动其他应用清空列表，ON/关机/重启/切换型号清空参数与列表。

数值引擎使用有迭代上限的正则化 beta/gamma、对数域 PMF、稳定正态尾概率和二分逆分布，避免直接阶乘溢出和小尾部的 `1 - CDF` 消减。测试含手册的 N=5、p=0.5、x={2,3,4,5} 例子和 x=36、μ=35、σ=2 的正态密度例子；测试不构成真机精度认证。

**输入域限制：** 本地实现把二项 N、离散 x 和泊松 λ 限于 1000000（整数要求只适用于 N/x），泊松 λ 必须为正。逆正态只接受严格位于 (0,1) 的面积，端点会明确报错，未复现真机端点哨兵值。内部双精度、显示十位和手册所述最高六位分布精度不是固件逐位等价声明。

### 数据表格

- 实际可编辑 A1:E45 共 225 格，方向键移动，EXE/Enter 确认并移至下一行。直接键入会替换当前格；点击编辑框或工具中的「编辑单元格」可修改原内容。
- 不带 `=` 的表达式计算一次成为常数，按说明书保留十位有效数字；以 `=` 开头的公式在上游变化时重算。
- 相对引用以及 `$A1`、`A$1`、`$A$1`；`Sum/Mean/Min/Max(A1:B3)` 矩形范围计算。空格作为 0 参与算术，聚合忽略空格；空范围 Sum 为 0，其他聚合报错。
- 工具提供公式填充、数值填充、复制/剪切/粘贴、全部删除、剩余容量和重算。复制平移相对引用，剪切保持引用，越界复制产生可见错误格。循环单格输入拒绝并保留旧数据，公式填充产生的错误显示在相应格中。
- 49 输入字节、1700 总字节限制按文本词法模拟（函数命令计一个字节，常数 14 字节，公式额外 15 字节）。这不是厂商固件编码；固件连续依赖链的额外内存阈值未复现。
- ON/关机清空整个表，切换应用时保留。表格只存在内存中，重启或切换型号清空，不写入历史/设置存储。语言、历史、变量、f/g、显示设置依然各型号独立保存。

手册的 35、42、49 和 Sum=126，以及公式填充 `2A1-3` 和数值填充 `B1×3` 均有独立计算与 Electron 操作测试。

## 仍未达到原机一致的部分

状态保持为 **Experimental**。尚未实现全部原生 CATALOG/TOOLS/SETTINGS 路径、自动计算关闭、编辑框只显示数值的选项、数据抓取、表格格值赋给变量、原机全部输入域/溢出/依赖链内存规则。电子表格采用可滚动线性编辑框，分布列表采用文本录入和结果行，数据输入页面仍有桌面适配；点阵字形、屏幕像素、全部按键状态和逐位结果未经实机比对。0.8.0 新增共用手册 p.55 的六类 47 项 CODATA 2018 常数，见 [USABILITY.md](USABILITY.md)。部分函数依靠电脑输入，不代表对应原机目录路径已完整实现。

操作公式时数字紧接 `E10` 有科学记数歧义，使用 `2*E10` 明确表示单元格乘法。复制模式中的源格使用其当前值/公式；尚未提供系统级表格剪贴板文件格式。

## English scope

The first-generation fx-999CN CW is selectable as **Experimental**, with a researched white chassis, 48-key CW layout and twelve-app HOME. It adds seven probability distributions and a functioning 45×5 spreadsheet to the existing CW subset. Distribution scalars carry approximate provenance; discrete lists support 45 inputs. Spreadsheet constants round to ten significant digits; formulas, relative/absolute references, aggregates, fill and copy/cut/paste are implemented. Spreadsheet data is volatile and clears on ON, power-off, model switch or restart. Firmware byte encoding, all native menus, all input domains and complete hardware parity remain unfinished. No firmware, official photograph or manufacturer logo is shipped.

Run `npm test`, `npm run build`, and on Windows `npm run test:ui:999` or the full `npm run test:ui`. Actual results are recorded in [VERIFICATION.md](VERIFICATION.md).
