# 功能兼容清单 · v0.1.0

本清单记录已提供的入口与测试范围，不声称固件或真机逐位等价。

| 范围 | 入口 | 验证方式 |
| --- | --- | --- |
| 基本/三角/对数/组合/坐标/度分秒 | 主界面与 F5 | 核心测试；四则、三角通过 UI 测试 |
| Σ/Π/积分/微分 | ∫ 键、SHIFT∫、SHIFTx、F5 | 核心解析值、角度链式因子、反向积分与奇点测试 |
| CALC / SOLVE | F6 / Shift+F6 | 变量测试、数值根/残差测试、SOLVE UI 测试 |
| 复数 | MENU 2 | 代数结果与非实数模式保护、UI 测试 |
| 基数 | MENU 3 | 四进制、逻辑、补码、错误输入；HEX UI 测试 |
| 矩阵 | MENU 4 | 逆矩阵、行列式、RREF；键盘定义及求 det |
| 向量 | MENU 5 | dot；键盘定义及求模；目录另提供 cross、夹角、单位化 |
| 统计与回归 | MENU 6 | 频数、四分位数、标准差及 7 种回归模型；单变量 UI |
| 函数表格 | MENU 7 | 双函数、正负步长、行数保护及 UI |
| 方程/函数 | MENU 8 | 2–4 元系统、2–4 次实根/复根/重根；二元和二次 UI |
| 不等式 | MENU 9 | 开闭区间、重根、孤立单点、全体实数、空集；UI |
| 比例 | MENU 0 | 两种类型及零输入保护；UI |
| 常数、换算、历史、设置 | F7、F8、F5、F11 | 数量/往返检查；常数和换算 UI |

尚待完整对照：所有原机函数的定义域、复数允许操作范围、矩阵病态输入、近邻根、极端回归数据、累计误差、工程符号和自然显示策略、二维输入光标、真机所有按键的操作步骤。当前版本须按 README 的差异清单使用。
