# fx-CG50 实验实现 / Experimental profile · 0.13.0 local

本型号保持 **Experimental**。它依据官方资料提供原创桌面图形界面和共享数学引擎上的已验证子集，不包含厂商固件、位图或 Logo，不是完整仿真或原厂认证。

本页按 2026-11-01 源码更新，最终构建与部署状态见 [验收记录](VERIFICATION.md) 和 [逐章手册账本](CG50_MANUAL_AUDIT.md)。当前 19 个主菜单应用均有实际工作流，但“能进入应用”不等于全部手册功能复刻。本轮无实体真机；已取得公开作者的原始程序文件及原厂资源样本，具体来源与验证范围见逐章账本。逐键、逐像素、全部错误域、末位数值和真实设备文件互操作仍未完成对照。应用与资源上限另见 [CG50_APPLICATIONS.md](CG50_APPLICATIONS.md)。

本地实现保存 20 个图形槽，支持 Y=f(X)、X=f(Y)、极坐标 r=f(θ)、参数曲线 X(T)/Y(T) 及 X/Y 严格或非严格不等式阴影。关系列表屏内软菜单依次为 SELECT、DELETE、TYPE、TOOL、MODIFY、DRAW；六个实体键帽始终是 F1–F6。SHIFT 副标签依次为 Trace、Zoom、V-Window、Sketch、G-Solv、G↔T。视窗更改清除旧曲线，随后需 DRAW；Xscale/Yscale 控制轴刻度，Xdot 与 Xmax 按画布宽度联动；Tθ 范围与步长供极坐标/参数图形使用。

## GRAPH 屏幕与软菜单依据

官方软件手册 5-1、5-2 的并排截图表明：关系列表底部有 SELECT / DELETE / TYPE / TOOL / MODIFY / DRAW；执行 DRAW 后的普通图形屏没有继续显示这排列表菜单。Trace、Zoom、V-Window 与 G-Solv 由相应 SHIFT 功能入口进入，不能永久改写 F1–F6 的实体键帽。

已核对的 TOOL 入口有 STYLE、GPH-MEM、BUILT-IN，分别见手册 5-17、5-19、5-37。STYLE 的 Normal、Thick、Broken、Dot、Thin（5-3）按槽保存。GPH-MEM 提供 20 组图形设置的存储/恢复/删除；BUILT-IN 提供线性、平移二次、二次、三次、正弦、余弦、正切共 7 个模板。模板写入当前图形槽，参数仍由计算引擎求值。

MODIFY 实现图上变量调参（5-36–5-37）：单个被修改表达式包含 1–5 个变量；图下显示变量值和 Step，当前项为紫色；上下选择项，左右按 Step 增减，允许直接输入值，EXIT 退出。SKETCH 提供清除、切线/法线、逆图、点及点开关、线/线段、圆、水平/垂直线、笔迹和文字；绘制内容保存在图形工作区，并受项目对象数量限制。这些是独立渲染流程，未认证全部原机细节。

Main Menu 依次为 1 Run-Matrix、2 Statistics、3 eActivity、4 Spreadsheet、5 Graph、6 Dyna Graph、7 Table、8 Recursion、9 Conic Graphs、A Equation、B Program、C Financial、D Geometry、E Picture Plot、F 3D Graph、G Memory、H System、I Link、J E-CON4。矩阵、向量和进制属于 Run-Matrix。前十二格顺序可见[官方快速指南总册](https://edu.casio.com/support/qsg/pdf/fx-CG50/All_CASIO_QuickStartGuide_fx-CG50.pdf)开头 Main Menu 图；后续应用按软件手册和当前型号配置开放。

Statistics 提供六个 List Files、26×999 列表、三组统计图、十二种回归、检验/置信区间和八类分布；Spreadsheet 支持 A1:Z999 的数值/文本/公式及 CSV；Recursion 支持 a/b/c 三序列。Program 为有预算的 BASIC 解释器，支持 a+bi 标量、实数列表/矩阵、持久 Pict/Capture 图像库，以及按已保存统计配置执行 DrawStat。Financial、Geometry、Picture Plot、eActivity、Memory/System/Link 和 E-CON4 的具体操作与限制见 [CG50_APPLICATIONS.md](CG50_APPLICATIONS.md)。

3D Graph 提供有限采样的 Z=f(X,Y)、球面、沿坐标轴的圆柱面、一般平面和参数直线，可旋转、缩放及切换线框。System 的亮度和自动关机是软件显示/定时器模拟。Link 支持模拟器 JSON 备份、G3M 不透明记录检查/保留，以及指定无页脚 CP0001 RGB565 G3P 图片编解码；G3M 程序 token、G3E eActivity 条带和 EA200 原生协议未实现，不能据此宣称完整原厂文件或外设兼容。

## 图形数学接口

图形分析包括 MAX/MIN/截距/交点、Y-CAL/X-CAL/指定区间积分；缩放包括 IN/OUT、FACTOR/AUTO/ORIGINAL/SQUARE/PREVIOUS、BOX/ROUND/INTEGER。早期入口、参考页码和数值边界见 [USABILITY.md](USABILITY.md)。分析功能按关系类型限制可用性，不把不能计算的结果填为零。

`src/engine/graph.js` 不读取 DOM，复用 Calculator 的安全编译、变量与角度设置。

| 接口 | 结果 |
| --- | --- |
| `validateGraphWindow(options)` | 验证并补全 xmin/xmax/ymin/ymax/samples |
| `sampleGraph(calc, expressions, options)` | Y=f(X) 的兼容接口；返回 `{window,samples,curves,warnings}`，每条曲线含原始 `index`、`expression`、`segments` 和 `invalidPoints` |
| `sampleGraphRelations(calc, relations, options, parameter)` | 按关系类型采样 Y/X/极坐标/参数/不等式；返回曲线分段及类型相关元数据 |
| `validateGraphParameter(options)` | 验证极坐标/参数范围与步长 |
| `graphRelationPoint(calc, relation, parameter)` | 计算关系上的 `{x,y,parameter}` 点，极坐标另含 `r`，供 Trace 使用 |
| `graphValue(calc, expression, x)` | 给定 x 的有限实数 y；无定义点明确报错 |
| `graphRoot(calc, expression, left, right)` | 扫描并返回一个通过残差检查的数值实根；不保证全部根 |

`segments` 是由 `{x,y}` 数学坐标组成的分段数组。窗口裁切、线色和屏幕坐标转换由渲染层负责。空白函数槽不会生成占位零结果；二维编辑器传入的仍是项目表达式，不使用 JavaScript eval。

## 数值边界

- Graph 的各类关系、Dynamic、Conic 和 3D 均为实值有限采样；Program 和其他应用有各自独立入口与预算。通用 CAS、固件执行和整机完整复刻不在已完成声明内。
- 采样使用一次编译、缓存与有预算的自适应中点检查。基本极点和定义域间断会分段；有限采样无法证明连续，也可能遗漏狭窄区间、快速振荡或非常接近的特征。
- 普通图形窗口端点绝对值最多 `10^12`，每条采样区间数 32–2048；极坐标/参数、动态和 3D 另有样本/帧预算。这些是本项目的资源限制，不是厂商规格。总求值预算防止复杂函数长时间阻塞桌面界面。
- 随机数、嵌套数值微积分/求和，以及可能包裹它们的 f/g 注册别名不作为逐像素函数；相应计算仍可在普通计算入口使用。
- ROOT 扫描区间寻找候选符号变化或恰好采到的零点，再求根并检查残差。极点的符号变化不能单凭区间变窄被接受。未采到的切根或紧邻根可能漏检；不作全根认证。
- 采样、追踪与求根不改动用户变量或 Ans；MODIFY 则按用户操作更新所选参数变量。结果是双精度数值，显示应保留近似语义。

核心及 Electron 用例覆盖图形采样、角度/定义域、求根/分析、类型/工具、应用路由、统计/程序/财务/工作区与状态保存。实际执行证据见 [VERIFICATION.md](VERIFICATION.md)。测试结果仅对应本项目用例；不等同实体机全部操作或末位等价，也未完成用户要求的全部手册验收。
